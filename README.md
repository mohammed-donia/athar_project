# أثر (Athar)

> سجّل حياتك، شوف تقدمك

تطبيق ويب عربي لتتبع أي شي قابل للقياس — دراسة، رياضة، قراءة، مصاريف، أو أي شي ثاني. 
بدل ما تحتاج تطبيق منفصل لكل شي، **أثر** يعطيك نظام واحد مرن.

## ✨ المميزات

- 🎯 **متابعات عامة** — أنشئ متابعة لأي شي (ساعات، كيلومترات، صفحات، أكواب، شيقل...)
- 📊 **أهداف مرنة** — يومي / أسبوعي / شهري، مع شريط تقدم تفاعلي
- ⚡ **Quick Add** — زر عائم لإضافة سريعة من أي صفحة
- 📈 **إحصائيات ورسوم** — Bar Chart + Line Chart لكل متابعة
- 📅 **Timeline كامل** — كل نشاطاتك مجمعة حسب اليوم
- 🌙 **Dark Mode** — فاتح / داكن / تلقائي
- 💾 **Local-first** — كل بياناتك على جهازك، بدون حساب أو إنترنت
- 📤 **Export / Import** — احتياطي بياناتك بملف JSON
- 🎨 **RTL كامل** — عربي أصيل من الأساس
- 📱 **Mobile-first** — يشتغل بشكل ممتاز على الجوال

## 🛠️ التقنيات

- **React 18** + **TypeScript**
- **Vite** — بناء سريع
- **React Router v6** — التنقل
- **Zustand** — إدارة الحالة
- **Tailwind CSS** — التصميم
- **Recharts** — الرسوم البيانية
- **date-fns** — معالجة التواريخ
- **Lucide React** — الأيقونات
